Try it

  1. Reload the page. Both ids stay, and the stored id is marked as seen before.
  2. Open this page in a private window. The stored id is new. Whether the fingerprint id is the same depends on what the browser lets a private window see.
  3. Open it in another browser on this device. Where both browsers expose the same values, the fingerprint id matches.
